# weighing_data_QR

Data for the lab weighing app (girish-vastrakar/weighing-beta, QR scanning and batches).
The phones write data.json, timestamps.json and corrections.json; names.json comes from the Name Tags sheet (NameSync.gs);
the results job (scripts/compute_results.py) writes results.json, results.csv, retest.json, retest.csv and corrections.csv.

This repository is public: anyone can read these files.

test-archive/2026-10-24/ holds the made-up test samples (Q01 to Q20) from trying the beta.
